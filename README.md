
# +Aproveitamento 🌱
Menos desperdício, mais impacto.

Plataforma que evita o desperdício de alimentos no comércio de bairro, pelo WhatsApp e por um site, sem precisar de app.

## Como funciona
1. O dono manda áudio, foto ou texto com a sobra pelo WhatsApp, e a IA organiza.
2. A sobra é vendida com desconto até o horário escolhido (site e QR Code).
3. O que não vender vira doação automática para uma ONG próxima.
4. Um motorista parceiro faz a entrega, paga com pontos, com sacola lacrada e código.
5. A ONG confirma com foto e o doador vê o impacto.
